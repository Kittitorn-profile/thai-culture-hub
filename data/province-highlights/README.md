# จุดหมายเด่นรายจังหวัด

คัดรายชื่อเพื่อเริ่มต้นสำรวจจังหวัด ไม่ใช่อันดับความนิยม สถิตินักท่องเที่ยว หรือการรับรองว่าสถานที่เปิดให้เข้าชมปัจจุบัน

- 77 จังหวัด จังหวัดละ 2–4 จุดหมาย รวม 208 แห่ง
- ตรวจ 8 พฤศจิกายน 2569 กับไฟล์แหล่งท่องเที่ยว ททท. 8,634 แถว และชื่อ/จังหวัดของสถานที่ในฐานข้อมูลจริง
- `highlights.json` เก็บชื่อเต็ม ชื่อสำหรับจับคู่ รหัสรายการต้นทาง จังหวัด และลิงก์ชุดข้อมูล ททท.
- `curated-candidates.json` เป็นรายการเริ่มต้นที่คัดโดยผู้จัดทำ ไม่ใช้ลำดับแถวหรือจำนวนภาพจัดอันดับ
- `review-report.json` ระบุรายชื่อที่ยังจับคู่ไม่ได้และไม่นำมาแสดง
- `public-coverage-audit.json` ตรวจผ่าน API ที่หน้าเว็บใช้จริงครบ 77 จังหวัด พบรายการแสดงได้ทั้งหมด 208 แห่ง ไม่มีจังหวัดที่เหลือน้อยกว่า 2 แห่ง

ต้นทาง: https://datacatalog.tat.or.th/dataset/87442079-88ec-42eb-b507-dcf135fc4301/resource/9348705e-18b4-4815-8d2c-0fd2f649e88e

ชื่อที่คล้ายกันต้องจับคู่เฉพาะสถานที่หลักที่ทบทวนแล้ว เช่น ไม่ใช้ด่านเชียงคานแทนถนนคนเดินเชียงคาน และไม่ใช้พิพิธภัณฑ์พระพุทธชินราชแทนวัดใหญ่ ข้อมูลยโสธรมีรูปสะกด ธาตุก่องข้าวน้อย/พระธาตุก่องข้าวน้อย ซึ่งตรวจชื่อเทียบแล้วจึงเก็บเป็นชื่อเดียวกัน

รายการมหาสารคามคงคำอธิบายและแหล่งอ้างอิงจากหน่วยงานจังหวัดที่ตรวจไว้ก่อนหน้าใน `province-highlights.ts`

หน้าเว็บใช้รายการสถานที่ที่โหลดมาอยู่แล้ว จับคู่ชื่อแบบตรงตัวหลังปรับช่องว่างและ Unicode ไม่เพิ่มคำขอ API และไม่สร้างสถานที่/พิกัดที่ไม่มีอยู่ ภาพใช้เฉพาะภาพเดิมของสถานที่เดียวกัน ไม่มีภาพจะแสดงข้อความแทน ไม่คัดลอกภาพหรือบทความเพิ่มเติม

## สร้างใหม่

`scripts/build-province-highlights.py` ใช้ไฟล์ต้นทางที่ดาวน์โหลดไว้ `/tmp/hub-official-attraction.json` และรายการสถานที่จาก ททท. ที่อ่านจากฐานข้อมูล `/tmp/hub-tat-highlight-candidates.json` สร้าง JSON และรายงานใหม่ หลังสร้างต้องทบทวนชื่อและตรวจผ่าน API จังหวัดก่อนเผยแพร่
