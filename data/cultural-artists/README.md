# ข้อมูลศิลปินทางวัฒนธรรม

รวบรวมเมื่อ 8 พฤศจิกายน 2569 เป็นข้อมูลจริงจากหน่วยงานรัฐ มหาวิทยาลัย และสื่อผู้เผยแพร่ผลงาน ไม่มีข้อมูล mock

## ขอบเขตชุดข้อมูลแรก

- 1,636 รายชื่อหลังรวมชื่อที่ตรงกัน
- 105 รายมีหลักฐานความเกี่ยวข้องกับจังหวัด ครอบคลุม 25 จังหวัด
- 1,531 รายยังรอยืนยันจังหวัด ไม่จัดลงจังหวัดโดยคาดเดา
- 223 รายมีข้อมูลสาขาหรือแนวดนตรี/การแสดงตามคำที่ปรากฏในต้นทาง
- ทำเนียบศิลปินแห่งชาติในแหล่งข้อมูลนี้ครอบคลุมปี 2528–2566 เป็นประวัติการยกย่อง ไม่ใช่การรับรองสถานะปัจจุบันหรือรายชื่อครบถึงปี 2569

## แหล่งข้อมูล

| ชุดข้อมูล | รายการต้นทาง | แหล่งอ้างอิง |
| --- | ---: | --- |
| ศิลปินแห่งชาติ | 367 | https://data.go.th/dataset/art_31_01 |
| ทะเบียนศิลปินร่วมสมัย | 1,120 | https://data.go.th/dataset/artist |
| ทะเบียนศิลปินศิลปาธร | 116 | https://data.go.th/dataset/silpathorn |
| ศิลปินพื้นบ้านจังหวัดเพชรบุรี | 60 | https://data.go.th/dataset/dataset_41_181 |
| บ้านศิลปินแห่งชาติ/แหล่งเรียนรู้ | 33 | https://data.go.th/dataset/lct_51_01 |

แหล่งชีวประวัติเพิ่มเติม เช่น กรมส่งเสริมวัฒนธรรม มหาวิทยาลัยมหาสารคาม มหาวิทยาลัยขอนแก่น และมหาวิทยาลัยเชียงใหม่ เก็บ URL ระดับรายบุคคลใน `sources` และ `provinceAssociations`

เก็บเงื่อนไขสิทธิ์ของแต่ละแหล่งใน `sources[].license` แหล่งเรียนรู้บ้านศิลปินระบุเงื่อนไขใช้เพื่อการศึกษา/ไม่ใช้เพื่อการค้า ไม่ได้นำรูปหรือข้อความชีวประวัติมาคัดลอกทั้งบทความ

## ความเกี่ยวข้องกับจังหวัด

- `birthplace`: แหล่งอ้างอิงระบุจังหวัดเกิด
- `origin`: ภูมิลำเนาตามชีวประวัติ
- `work_area`: พื้นที่ทำงาน/ทะเบียนศิลปินจังหวัด
- `learning_site`: บ้านศิลปินหรือแหล่งเรียนรู้
- `cultural_legacy`: ความเกี่ยวข้องจากผลงานและมรดกวัฒนธรรม

ไม่นำจังหวัดจากบ้านศิลปินไปอ้างเป็นจังหวัดเกิด ไม่เก็บที่อยู่บ้าน เบอร์โทรศัพท์ หรืออีเมลส่วนตัว ชื่อซ้ำรวมด้วยชื่อที่ปรับคำนำหน้าและช่องว่าง เก็บแหล่งอ้างอิงและประเภทของทุกแหล่งไว้ ไม่ยกระดับศิลปินพื้นบ้านหรือศิลปินท้องถิ่นเป็นศิลปินแห่งชาติ

## ที่เก็บและ API

- Snapshot: `registry.json`
- ฐานข้อมูล: `home_content_sections`, key `province-artists-v1` (แยกออกจาก payload หน้าแรก)
- `GET /api/cultural-artists/`
- กรอง `provinceCode=TH-40`, `type=national_artist`, `genre=หมอลำ`, `q=ชื่อ`, `page=1`, `pageSize=24`
- เมื่อกรองจังหวัด จะคืนเฉพาะรายชื่อที่มีหลักฐานจังหวัดนั้น ประเภทความเกี่ยวข้องอยู่ในแต่ละรายการ

การเตรียม CSV ต้นทาง: `python3 scripts/prepare-cultural-artists.py /path/to/downloaded-csvs`

ตรวจข้อมูลก่อนนำเข้า: `node scripts/import-cultural-artists.cjs`

นำเข้าครั้งแรก: `node scripts/import-cultural-artists.cjs --apply` จะปฏิเสธหากมีชุดข้อมูลนี้อยู่แล้ว เพื่อไม่ทับข้อมูลที่ตรวจสอบหรือแก้ไขภายหลัง

โปรไฟล์ที่เพิ่มจากหลักฐานสื่อ เช่น สุรพล ทองด้วง (อ๊อฟ สุรพล) อ้างอิง Thai PBS และ Workpoint แยกรางวัลประกวดใน `awards` จากการยกย่องใน `recognitions` ชื่อในวงการและรูปสะกดสำหรับค้นหาเก็บใน `aliases` เพิ่มรายการตรวจสอบแล้วใน `supplements.json` เพื่อไม่ให้หายเมื่อเตรียม CSV ใหม่


## ชุดเสริมศิลปินนักร้อง/นักดนตรี

`performers.json` เพิ่ม 33 รายชื่อจากข่าวต้นสังกัด ผู้จัดรายการ และบทสัมภาษณ์ รวมศิลปินลูกทุ่งและหมอลำที่อยู่นอกทะเบียนรัฐ ไม่ได้จำกัดตามอายุหรืออ้างว่าครบทุกคน มี 7 รายยืนยันจังหวัดแล้ว อีก 26 รายรอตรวจจังหวัด

ตัวอย่าง: เวียง นฤมล (ร้อยเอ็ด), เบียร์ พร้อมพงษ์ (ชัยภูมิ), เต๋า ภูศิลป์ และบิว จิตรฉรีญา (อุบลราชธานี), แอน อรดี (จังหวัดเกิดขอนแก่น), บอย ศิริชัย (พื้นที่ทำงานมหาสารคาม), อุ๋งอิ๋ง รัตนาภรณ์/เพชรบ้านแพง (ศรีสะเกษ)

แหล่งหลัก: [Grammy Gold](https://www.gmmgrammy.com/newsroom/news-single.php?id=4381), [ประวัติเวียง นฤมล](https://www.gmmgrammy.com/newsroom/news-single.php?id=9388), Workpoint หมอลำไอดอล และชีวประวัติ/บทสัมภาษณ์ใน `sources` รายบุคคล เก็บเฉพาะชื่อ แนวเพลง และข้อเท็จจริงสั้น ๆ ไม่คัดลอกบทความหรือรูปภาพ

ประเภท `performing_artist` หมายถึงศิลปินนักร้อง/นักดนตรี ไม่ใช่ทะเบียนศิลปินร่วมสมัยหรือศิลปินแห่งชาติ ชื่อหลักอาจเป็นชื่อในวงการ ไม่อ้างว่าเป็นชื่อทางกฎหมาย ไม่เก็บสังกัดปัจจุบันหรือสถานะศิลปินอิสระจากข่าวเก่า จังหวัดที่เป็นที่จัดงาน/ที่ถ่าย MV/ที่ศึกษาไม่ถูกนำมาเดาเป็นภูมิลำเนา

ตรวจแผนการเพิ่มเข้าฐานข้อมูล: `node scripts/merge-cultural-artists.cjs`

นำเข้าจริง: `node scripts/merge-cultural-artists.cjs --apply` รวมรายชื่อและแหล่งอ้างอิงโดยรักษาข้อมูลเดิม ปฏิเสธชื่อกำกวม ใช้ `updated_at` ป้องกันเขียนทับการแก้ไขที่เกิดพร้อมกัน นำเข้าซ้ำได้โดยไม่เพิ่มรายการซ้ำ

ปรับ snapshot ใน repo: `node scripts/merge-cultural-artists.cjs --snapshot` หรือเตรียม CSV ใหม่ซึ่งจะรวม `supplements.json` และ `performers.json` ให้อัตโนมัติ
