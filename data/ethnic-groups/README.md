# ชุดเสริมชุมชนชาติพันธุ์และพิกัด

รวบรวมจากวิกิชุมชน ศูนย์มานุษยวิทยาสิรินธร ตรวจเมื่อ 8 พฤศจิกายน 2569

- ทบทวน 29 หน้าชุมชน รับ 26 รายการ พร้อมจังหวัด อำเภอ ตำบล กลุ่มชาติพันธุ์ และพิกัด
- ไม่รับ SAC 1556 เพราะไม่พบหลักฐานชื่อกลุ่มในช่องชาติพันธุ์ที่ดึงได้
- พัก SAC 478 และ 1521: ชุมชนป่าละอูเดียวกัน แต่พิกัดต่างกัน ต้องตรวจจุดอ้างอิงเพิ่มเติมก่อนนำเข้า
- เก็บคำอธิบายสั้นที่เรียบเรียงใหม่ ไม่คัดลอกชีวประวัติ/บทความเต็ม ภาพ เบอร์โทรศัพท์ หรือข้อมูลติดต่อบุคคล
- พิกัดเป็นจุดอ้างอิงชุมชนที่ต้นทางเผยแพร่ ตรวจค่าตัวเลขและเทียบ marker ในแผนที่เมื่อมี ไม่ใช่ผลสำรวจภาคสนามหรือขอบเขตที่อยู่อาศัยทั้งหมด
- ชุมชนหนึ่งมีหลายกลุ่มชาติพันธุ์ได้ เก็บใน `groups` ไม่เลือกกลุ่มเดียวแทนทั้งหมด
- คงรูปสะกดชื่อกลุ่มตามต้นทาง ชื่อภาษาไทยและอังกฤษอาจหมายถึงกลุ่มเดียวกัน สถิติชื่อกลุ่มจึงไม่ใช่จำนวนชาติพันธุ์ที่แตกต่างกันทางวิชาการ

## ไฟล์และฐานข้อมูล

`community-supplements.json` — ข้อเท็จจริงที่ทบทวนแล้ว แต่ละรายการมี `sourceUrl`, `coordinateSourceUrl`, `coordinateKind`, `checkedAt`

`preparation-report.json` — รายการที่พัก/ไม่รับพร้อมเหตุผล

จัดเก็บใน `home_content_sections` key `ethnic-community-supplements-v1` แยกจาก `ethnic_groups` เดิม เพื่อรักษาข้อมูลและแหล่งอ้างอิงเดิมทั้งหมด ไม่รวมใน payload หน้าแรก

หน้า `/admin/ethnic-groups/` และภาพรวมชุดข้อมูลอ่านรวมกับชุดเดิม ส่วนหน้า Sync แสดงจำนวนต้นฉบับและชุดเสริมแยกกัน

## เตรียมและนำเข้า

1. `python3 scripts/prepare-ethnic-community-supplements.py` อ่าน metadata และพิกัดที่ระบุชัดจากหน้าชุมชนที่เลือก ไม่เดาจากศูนย์กลางจังหวัด
2. ทบทวนผล ชื่อซ้ำ และจุดอ้างอิงก่อนนำเข้า
3. `node scripts/import-ethnic-community-supplements.cjs` ตรวจเทียบกับชุมชนเดิมแบบ dry-run
4. `node scripts/import-ethnic-community-supplements.cjs --apply` เพิ่มเฉพาะรายการใหม่ เก็บรายการเดิม ใช้ timestamp ป้องกันเขียนทับเมื่อมีคนแก้ไขพร้อมกัน และนำเข้าซ้ำได้
