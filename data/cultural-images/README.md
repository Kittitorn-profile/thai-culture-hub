# Verified cultural images

`fabric-images.json` links records to published images on the Queen Sirikit Department of Sericulture (QSDS) silk-conservation information website.

Matching requires the dataset title to appear in the source page title, plus either matching image alt text or manual visual review of the photograph in that page. Each entry records the dataset ID, title, province, image URL, credit, source page, and verification date. The source image is linked directly, not copied into this repository. This manifest does not assert an open license or ownership of the images. Existing dataset image URLs take precedence. Unknown or unmatched records keep the normal placeholder.
