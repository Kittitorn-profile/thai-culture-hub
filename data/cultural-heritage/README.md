# วิถีชีวิตและการทอผ้า

ชุดรวบรวมเพิ่มเติม 8 เรื่อง ใน 6 จังหวัด ตรวจแหล่งข้อมูล 8 พฤศจิกายน 2569

- กาฬสินธุ์: ผ้าไหมแพรวาบ้านโพน
- เชียงใหม่: ผ้าจกแม่แจ่ม และเรื่องความเชื่อ/การแต่งกาย
- แพร่: ผ้าจกเมืองลอง
- ตรัง: ผ้าทอนาหมื่นศรี และการสืบสานอาชีพของชุมชน
- สงขลา: ผ้าทอเกาะยอ
- สกลนคร: ผ้าฝ้ายย้อมครามบ้านคำข่า

เก็บใน `community-weaving.json` เป็นบทสรุปเรียบเรียงจากหน่วยงานต้นทาง พร้อม URL และชื่อผู้เผยแพร่รายเรื่อง ไม่คัดลอกภาพ/บทความเต็ม ไม่อ้างสถานะ GI หรือขึ้นทะเบียนมรดก ไม่เดาพิกัด ที่อยู่ส่วนตัว หรือรายชื่อผู้สืบทอด ความเชื่อระบุเป็นเรื่องเล่าทางวัฒนธรรมตามแหล่ง ไม่ใช่ข้อเท็จจริงเชิงวิทยาศาสตร์หรือข้อสรุปถึงทุกคนในชุมชน

แสดงที่ `/admin/cultural-heritage/` ปุ่ม **วิถีชีวิตและผ้าทอ · ชุดรวบรวมเพิ่ม** แยกจากทะเบียน CKAN และไม่เพิ่มเข้า `cultural_places` เพราะเป็นเรื่องภูมิปัญญา ไม่ใช่พิกัดสถานที่

API เดิมรองรับ `collection=community` พร้อม `q`, `province`, `page`, `limit` ภายใต้สิทธิ์ `cultural_heritage` ไม่ต้องแก้ฐานข้อมูลและไม่เรียก CKAN สำหรับชุดนี้

## ชุดเสริมทอเสื่อ จักสาน และศิลปาชีพ

`community-crafts.json` เพิ่ม 7 เรื่อง รวมกับชุดผ้าทอเดิมเป็น **15 เรื่อง ใน 12 จังหวัด**

- เสื่อกกจันทบูร — จันทบุรี
- สาดไตหย่า — เชียงราย
- จักสานพนัสนิคม — ชลบุรี
- ผลิตภัณฑ์จักสานกระจูดบ้านห้วยลึก — สุราษฎร์ธานี
- กลุ่มจักสานบางเจ้าฉ่า/แหล่งเรียนรู้ OTOP — อ่างทอง
- ศูนย์ศิลปาชีพบ้านกุดนาขาม — สกลนคร
- ศูนย์ศิลปาชีพบางไทร — พระนครศรีอยุธยา

ใช้หมวด `OTOP ตามแหล่งอ้างอิง` เฉพาะรายการที่ผู้เผยแพร่ระบุ ไม่อ้างระดับดาว การขึ้นทะเบียน หรือสถานะปัจจุบัน ศูนย์ศิลปาชีพเก็บเป็นเรื่องบทบาท/ประวัติ ไม่ใช้แทนข้อมูลเปิดบริการปัจจุบัน

ปุ่มในแอดมินเปลี่ยนชื่อเป็น **วิถีชีวิตและหัตถกรรมชุมชน** รองรับตัวกรองหมวดผ่าน `collection=community&category=...` พร้อมตัวกรองคำค้นและจังหวัด สถิติจำนวนเรื่อง/จังหวัดคำนวณจากข้อมูลทั้งหมด ไม่เปลี่ยนตามผลค้นหา
